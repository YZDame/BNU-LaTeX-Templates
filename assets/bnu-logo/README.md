# 北京师范大学校名与校徽（TikZ）

本目录来自 [leyudame/BNU_icon_Tikz](https://github.com/leyudame/BNU_icon_Tikz)，按上游许可证 **GPL-3.0** 原样收录。`LICENSE` 是 GPL-3.0 全文，只约束本目录，不把仓库里其余模板改成 GPL。

| 文件 | 用途 |
| --- | --- |
| `BNU_icon_Tikz.tex` | 校徽的 TikZ 源文件 |
| `BNU_icon.pdf` | 由上述源文件生成的校徽，幻灯片封面使用 |
| `BNU_name.pdf` | 校名图，课程论文封面和简历页眉使用 |
| `LICENSE` | GNU GPL-3.0 |

这是社区重绘的矢量图，不是北京师范大学发布的官方标识文件。使用前请自行核对学校的标识规范。学位论文模板 `templates/thesis/figures/` 里的校名图来自图书馆论文系统的官方模板，与本目录不是同一份文件，请不要互相替换。
